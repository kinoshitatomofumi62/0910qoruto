📖 16属性クォルトのルール

16種類のカードには4つの属性があります：
1. 背景色: 赤 / 青
2. 外枠形状: 四角 / 丸
3. 中央マーク: 星 (★) / ハート (♥)
4. マーク色: 黄 / 緑

⭐ 最大の特徴: 自分が置くカードは、相手が選んで渡してくれたカードです！

縦・横・斜めの4マスにおいて、どれか1つの属性が4枚共通した瞬間「クォルト」達成となり、カードを置いたプレイヤーが勝利します！
